### ✨ Features

- **📚 All 128 Official Questions:** Covers complete USCIS 2027 civics syllabus
- **🎙️ Audio Learning:** Listen to questions & answers with clear pronunciation
- **📝 Real Mock Test:** Exam-like interface with timer and scoring
- **✅ 65/20 Special Category:** Separate section for 65/20 applicants (100 questions)
- **📴 100% Offline:** Study anywhere, no internet required
- **🌙 Light & Fast:** Built with Flutter, clean UI
